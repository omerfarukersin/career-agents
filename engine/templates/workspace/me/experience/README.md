# Experience bank

One file per job, internship, project, society role or volunteering. **Put in more than any CV would hold** — writers select from here.

Name files like `2024_internship_CompanyName.md`, `2026_project_customer-churn.md`, `2023_society_TreasurerX.md`.

Copy this template for each:

```markdown
# <Title>, <Organisation>
- Type: internship | job | academic project | dissertation | society | volunteering | personal project
- Dates: MMM YYYY – MMM YYYY
- Location:
- Tools / methods: (Python, SQL, regression, Excel, Tableau, Jira...)

## What I did (raw, as many bullets as you like)
- 
- 

## Results / numbers (anything measurable, even approximate — say "approx.")
- 

## What this proves (skills a recruiter would care about)
- 
```

Experience from any field counts: shifts, site work, society roles and coursework all show quantitative thinking, stakeholder work and delivery. Writers translate it into the target role's language without changing the facts.
