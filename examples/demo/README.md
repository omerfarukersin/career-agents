# Demo: Alex Quinn applies to Harbourline Energy

Everything in this folder is **fictional**: the candidate, the university, the employer and the posting. It shows what the pipeline produces for one job, start to finish.

| File | Made by |
|---|---|
| `me/` | the career bank a user builds with `/build-career-bank` |
| `jobs/.../job.md` | `job-scout` (the saved posting) |
| `jobs/.../analysis.md` | `job-analyst` (requirements, evidence, fit score, gaps) |
| `jobs/.../cv.tex`, `cv.pdf` | `cv-writer` |
| `jobs/.../cover_letter.tex`, `cover_letter.pdf` | `cover-letter-writer` |
| `jobs/.../critique.md` | `recruiter-critic` |

The demo `me/` has only the files the pipeline needs; a real workspace also has `answer_bank.md` and `questionnaire.md` from the starter templates.

To try it yourself: copy `examples/demo/me` and `examples/demo/jobs` to the repo root, open Claude Code and run `/add-job jobs/Harbourline-Energy/2026-11-02_Graduate-Data-Analyst`.
