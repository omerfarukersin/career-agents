# Data Intern, CityWorks Facilities (fictional)
- Type: internship
- Dates: Jul 2025 – Sept 2025
- Location: Dublin, Ireland
- Tools / methods: SQL, Python (pandas), Tableau

## What I did
- Wrote SQL queries against the maintenance-ticket database (about 40,000 tickets a year) to report response times by site.
- Replaced a weekly manual spreadsheet report with a Python script that pulled the data and produced the same tables; it ran in a few minutes instead of half a day.
- Built a Tableau dashboard of response times for the operations manager, used in the weekly site meeting.
- Found duplicate tickets created by the old logging form and wrote a short note on how to flag them.

## Results / numbers
- Weekly report time: from about half a day to a few minutes (approx.).
- Dashboard covered 12 sites.

## What this proves
- SQL, Python automation, dashboarding, data-quality checks, working with an operations stakeholder.
